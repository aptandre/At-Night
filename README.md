## _ à Noite.

{Dia} à Noite é um projeto oriundo de conversas muito profundas com um amigo na qual nós frequentemente discutimos que nos sentimos estranhamente mal todo Domingo à Noite. Fiz esse projeto para sempre que ele se sentir mal do nada poder checar qual é o dia da semana e concluir se é o mau do Domingo à Noite!
